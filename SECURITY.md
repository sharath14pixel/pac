# Security

This repository is a reference implementation from the BitGN PAC 2026 hackathon.
It is **not a maintained product**, and no security fixes will be published here.

If you find a security-relevant issue in the approach, in the defense layers
(B1–B5), or in how the agent interacts with the BitGN platform, and want to
discuss it responsibly, please contact Bernhard Götzendorfer directly via
[GitHub](https://github.com/Kanevry) or
[LinkedIn](https://www.linkedin.com/in/bernhardgotzendorfer/).

Please do **not** open public issues on this repository.
